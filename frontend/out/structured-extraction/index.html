Structured Extraction

ai_query with responseFormat

Unstructured text is not directly queryable in SQL. ai_query with responseFormat solves this by instructing the model to return a typed JSON struct — making every AI response directly filterable, aggregatable, and joinable.

Current industry: 🏦 Financial Services | Schema: main.ai_functions_workshop_fins

❌ Without responseFormat

Returns free-form text. Format varies per call. Cannot filter, aggregate, or join. Breaks at scale.

✅ With responseFormat

Returns a typed STRUCT. Every field is queryable with standard SQL. Consistent across millions of rows.

1

Understand your raw data

The product_documents table contains unstructured text in the document_text column. Our goal: make it queryable.

Preview the raw datasql
USE main.ai_functions_workshop_fins;

SELECT *
FROM product_documents
LIMIT 5;
2

Without responseFormat — unstructured output

⚠️

The problem

Free-text AI responses vary in format, use different field names, and cannot be reliably parsed with SQL. Try running 100 rows and notice how the output structure differs.
ai_query without responseFormatsql
SELECT
    product_id,
    ai_query(
        'databricks-meta-llama-3-3-70b-instruct',
        CONCAT('Summarize the key details from this text: ', document_text)
    ) AS raw_text_output  -- varies every call, not queryable
FROM product_documents
LIMIT 3;
3

With responseFormat — typed STRUCT output

💡

Use a json_schema responseFormat

Pass a json_schema string to responseFormat to define the output structure. The model returns JSON matching that schema; wrap the call in from_json(...) to get a typed STRUCT you can query field-by-field.
ai_query with responseFormat — structured extractionsql
SELECT
    *,
    from_json(ai_query(
        'databricks-meta-llama-3-3-70b-instruct',
        CONCAT('Extract key details from this fins record: ', document_text),
        responseFormat => '{"type":"json_schema","json_schema":{"name":"response","schema":{"type":"object","properties":{"product_name":{"type":"string"},"product_type":{"type":"string"},"apr_low":{"type":"integer"},"apr_high":{"type":"integer"},"min_income_usd":{"type":"integer"},"max_amount_usd":{"type":"integer"}}}}}'
    ), 'product_name STRING, product_type STRING, apr_low BIGINT, apr_high BIGINT, min_income_usd BIGINT, max_amount_usd BIGINT') AS extracted
FROM product_documents
LIMIT 20;
✅

What to notice

Each row now has a STRUCT column. Click a cell to expand it — every field has the correct type. You can query extracted.field_name directly in SQL.
4

Query the extracted fields with SQL

Save the extracted results in a CTE or table, then query the struct fields like any other column.

Aggregate extracted fields — real analytics from unstructured datasql
WITH extracted AS (
    SELECT
        *,
        from_json(ai_query(
            'databricks-meta-llama-3-3-70b-instruct',
            CONCAT('Extract key details: ', document_text),
            responseFormat => '{"type":"json_schema","json_schema":{"name":"response","schema":{"type":"object","properties":{"product_name":{"type":"string"},"product_type":{"type":"string"},"apr_low":{"type":"integer"},"apr_high":{"type":"integer"},"min_income_usd":{"type":"integer"},"max_amount_usd":{"type":"integer"}}}}}'
        ), 'product_name STRING, product_type STRING, apr_low BIGINT, apr_high BIGINT, min_income_usd BIGINT, max_amount_usd BIGINT') AS info
    FROM product_documents
    LIMIT 100
)
SELECT
    product_id,
    extracted.product_type,
    extracted.apr_low,
    extracted.apr_high,
    extracted.min_income_usd
FROM extracted_products
ORDER BY extracted.apr_low;
5

Save results to Delta Lake

Persist extracted resultssql
CREATE OR REPLACE TABLE main.ai_functions_workshop_fins.extracted_product_documents AS
SELECT
    *,
    from_json(ai_query(
        'databricks-meta-llama-3-3-70b-instruct',
        CONCAT('Extract structured details: ', document_text),
        responseFormat => '{"type":"json_schema","json_schema":{"name":"response","schema":{"type":"object","properties":{"product_name":{"type":"string"},"product_type":{"type":"string"},"apr_low":{"type":"integer"},"apr_high":{"type":"integer"},"min_income_usd":{"type":"integer"},"max_amount_usd":{"type":"integer"}}}}}'
    ), 'product_name STRING, product_type STRING, apr_low BIGINT, apr_high BIGINT, min_income_usd BIGINT, max_amount_usd BIGINT') AS extracted,
    current_timestamp() AS ai_processed_at
FROM product_documents;

-- Verify
SELECT COUNT(*), COUNT(extracted) AS rows_with_extraction
FROM main.ai_functions_workshop_fins.extracted_product_documents;
