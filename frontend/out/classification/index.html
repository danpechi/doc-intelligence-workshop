Classification & Extraction

ai_classify · ai_extract

Purpose-built functions for high-volume classification and entity extraction. No prompt engineering — just provide your label set or entity list and apply across any table.

Industry: 🏦 Financial Services | Table: main.ai_functions_workshop_fins.merchant_transactions

ai_classify(content, ARRAY(...))

Use when: You know the label set in advance

Returns: One label from your array — the best match

ai_classify(transcript, ARRAY('billing_issue', 'churn_risk', 'technical'))

ai_extract(content, ARRAY(...))

Use when: You need named entities from text

Returns: A STRUCT with one field per entity name

ai_extract(notes, ARRAY('batch_id', 'supplier', 'root_cause'))

ai_classify — Financial Services use case

ℹ️

Zero-shot classification

No fine-tuning, no training data. Just define your label set and the model infers the best match from context. Labels should be mutually exclusive and cover all cases.
Classify merchant_transactions — Financial Servicessql
SELECT
    *,
    ai_classify(
        merchant_name_raw,
        ARRAY('low_risk', 'medium_risk', 'high_risk', 'potential_fraud')
    ) AS ai_label
FROM merchant_transactions
LIMIT 50;

Validate against ground truth labels

Where your dataset has existing labels, compare them to the AI classification to measure accuracy.

Accuracy check — AI vs ground truthsql
-- fins: check classification consistency on product_documents
SELECT
    product_id, product_name,
    ai_classify(document_text, ARRAY('secured_loan','unsecured_loan','premium_credit_card','standard_credit_card')) AS product_type
FROM product_documents;
💡

Expected accuracy

For well-defined, mutually exclusive label sets on clear text, expect 75-90% agreement with human labels. For ambiguous categories, expect lower — and consider refining your label definitions.

ai_extract — pull named entities

Extract entities from merchant_transactionssql
SELECT
    *,
    ai_extract(
        merchant_name_raw,
        ARRAY('merchant_name', 'transaction_amount', 'currency', 'merchant_category')
    ) AS entities
FROM merchant_transactions
LIMIT 20;

-- Access individual fields
-- entities.merchant_name
-- entities.transaction_amount
ℹ️

Missing entities

If an entity is not present in the text, its field returns NULL. Use COALESCE or IS NOT NULL filters as needed.

Combine classify + extract in one pass

Both functions read the same column — combine them to enrich records in a single SQL statement without hitting the model twice unnecessarily.

classify + extract combinedsql
SELECT
    product_id, product_name,
    ai_classify(document_text, ARRAY('secured_loan','unsecured_loan','premium_credit_card','standard_credit_card')) AS product_type,
    ai_extract(document_text, ARRAY('minimum_income','maximum_amount','apr_range','loan_term')) AS terms
FROM product_documents;
5

Aggregate classified results for reporting

Analytics on AI-classified datasql
WITH enriched AS (
    SELECT
        *,
        ai_classify(merchant_name_raw, ARRAY('low_risk', 'medium_risk', 'high_risk', 'potential_fraud')) AS label
    FROM merchant_transactions
    LIMIT 200
)
SELECT
    label,
    COUNT(*)                                               AS record_count,
    ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (), 1)   AS pct_of_total
FROM enriched
GROUP BY label
ORDER BY record_count DESC;
